GestureSnake AI

Tagline

AI Powered Gesture Controlled Snake Game

--------------------------------------------------

## OBJECTIVE

Users register/login.

Users play Snake using AI hand gestures.

Camera tracks the hand.

Python detects gestures.

React receives movement commands.

Scores are stored in PostgreSQL.

Leaderboard updates in realtime.

Entire application is deployed.
